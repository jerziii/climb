How to use
  1. Pick Satellite below and zoom to the sector you care about.
  2. Screenshot a drawn sector map (guidebook page, planetmountain, ČHS) and press Ctrl/Cmd+V here — or drag the image file onto the map.
  3. Drag the 4 orange corners onto features you can identify on both images: road bends, forest edges, field corners, the chateau, the pond.
  4. Pull the opacity slider until you can see both. Now the drawn blobs sit on real terrain.
  5. Drop pins on the boulders you want, then Export GPX and open it in Mapy.cz / Locus / OsmAnd on your phone.

Everything is stored in your browser (localStorage for state, IndexedDB for overlay images and offline tiles). No server, no account — works offline once loaded, except map tiles and OCR scanning.

Sector index

Add a sector by coordinates

Decimal or degrees–minutes–seconds, in either order, with or without N/S/E/W: 50.065961, 13.341427 · 50°3'57.5"N 13°20'29.1"E · 50,0660 13,3414. Typing a name that is already in the index moves that sector instead of adding a second one. Paste the numbers, not a map link — a link's coordinate order cannot be trusted.

Names collected from the Petrohrad guidebook / planetmountain / ČHS listings. Starting positions for the researched sectors come from ČHS / theCrag / OSM (see research/petrohrad-boulders.md for sourcing and confidence per sector) — a sector also turns green when a live OSM match is found; sectors with no source anywhere still need Place and a click on the map once you've identified them under an overlay.

Offline maps

Save an area now, read it in the forest with no signal. Tiles are stored in the browser, per base map — download the layer you actually intend to use.

Radius Detail

Downloading is rate-limited on purpose. Tile servers are donated infrastructure and bulk scraping is against their usage policies — keep areas small and grab them once, not repeatedly.

Real climbing data (OSM)

Queries the Overpass API for sport=climbing, climbing=* and rock/cliff features in the current view. Czech crags are decently mapped — this is the ground truth to align your topo against.
